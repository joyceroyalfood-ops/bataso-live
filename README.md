# BATASO LIVE — Tây Sơn Edition

Một giao diện livestream theo phong cách BATASO, bố cục dọc 1080×1920, phù hợp OBS Browser Source và TikTok Live.

## Yêu cầu
- Node.js 20+
- npm

## Chạy dự án
```bash
npm install
npm run dev
```

Mở:
- http://localhost:5173/
- http://localhost:5173/?overlay=1

## Build production
```bash
npm run build
npm run preview
```

## Mục tiêu giao diện
- Tầng header thương hiệu BATASO với luật đơn giản và góc nhìn 3/4.
- Khu gian hàng host + bếp nướng + băng rôn đặc sản.
- Khu vỉa hè với ghế người xem, topper, và các avatar đặt chỗ.
- Footer chạy tin nhắn và box thông báo tương tác.
